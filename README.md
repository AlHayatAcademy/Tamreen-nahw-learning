# الحیات — آسان علم النحو

ڈاکٹر عمران حیات کی تدریسی پیشکش۔ اس مرتب نسخے میں نحو کے بنیادی اور تکمیلی مباحث ایک مربوط اردو نصاب میں ہیں۔

## شامل مواد

- 75 اسباق، 9 مراحل اور متعلقہ عنوانات کے اندر 157 تفصیلی ذیلی بحثیں۔
- ہر ذیلی بحث: قاعدہ یا شرط، مکمل عربی مثال، اردو ترجمہ، نحوی تحلیل اور سوال مع جواب۔
- ہر مرکزی مثال میں لفظی اعراب، جامع ترکیب، الفاظ و معانی، تقابلی مثال اور اصلاح۔
- 638 انتخابی سوالات؛ اصلاحی سوال دو انتخاب رکھتا ہے، دیگر میں چار۔
- ذیلی مباحث کی 157 کھلی مشقیں اور 9 مربوط عبارتوں کے 18 سوالات؛ 529 دہرائی کارڈ۔
- مرکزی لغت: 152 سیاقی اندراجات، 45 نحوی اصطلاحات، 147 ادواتی اندراجات اور استعمالات۔ یہ اعداد الگ مادوں یا اصل کتاب کے ہر نادر استعمال کی تعداد نہیں۔
- موضوع اور سوال کی نوعیت سے جانچ، ترکیب گاہ، تلاش، محفوظ اسباق اور پیش رفت کی منتقلی۔

## چلانا اور تعیناتی

ZIP نکالیں اور `index.html` کھولیں۔ تمام fonts مقامی، کوئی dependency/API/backend درکار نہیں۔

Cloudflare Pages: `nahw-learning` کے اندر کی فائلیں repository کی root میں رکھیں؛ framework None، build command خالی، output directory `/`۔ GitHub Pages پر بھی یہی directory شائع کریں۔ hash routes کو server fallback نہیں چاہیے۔ اصل PDFs شامل نہیں؛ مکمل code tree 25 MB سے کم ہے۔

## ترمیم

`content.json` بنیادی درسی مواد ہے؛ اس کی ترمیم کے بعد `node scripts/build-data.cjs` چلائیں۔ `vocabulary.js` مرکزی لغت، `terms.js` اصطلاحات اور `tools.js` ادوات کا مرجع ہیں۔ `reference.js` مختصر جدول ہیں۔ `app.js` میں routes، مشق، پیش رفت اور تلاش ہے۔ `styles.css` میں یکساں رنگ و typography اور آخر میں load ہونے والی `app-layout.css` میں viewport/drawer ترتیب ہے۔

اصل 68 اسباق اور سابقہ سوالات کے IDs محفوظ ہیں، اس لیے browser کی سابق پیش رفت برقرار رہتی ہے۔ نیا browser یا آلہ استعمال کرنے کے لیے progress export/import کریں۔ کوئی معلومات سرور کو نہیں بھیجی جاتیں۔

## ماخذ اور احاطہ

`coverage.json` اور `editorial/COVERAGE_MAP.md` میں فہرستوں کے 145 موضوعاتی اندراجات نئے اسباق سے جوڑے گئے ہیں۔ `editorial/SOURCE_AND_COVERAGE.md` میں ماخذ سے استفادہ اور جائزے کی حدود درج ہیں۔ مرتب مواد اصل کتب کی لفظی نقل نہیں۔

## جانچ

```
node --check app.js
node tests/smoke.cjs
python3 tests/contrast.py
```

225 درسی views، سوالات، retry/scoring، import، محفوظ اسباق، لغت، ادوات، 9 عبارتیں اور source-topic links جانچے گئے۔ 140 رنگ/پس منظر/state/accent جوڑوں میں تناسب کم از کم 5.66:1 ہے۔ ہر سبق کا الگ گہرا accent ہے؛ اصل پڑھنے کا متن مستقل واضح رنگ میں ہے۔

حقیقی browser rendering کی جانچ اس ماحول میں دستیاب نہیں تھی۔ simulated DOM اور عددی رنگ جانچ، screenshot یا actual overflow measurement کا بدل نہیں۔ desktop/mobile پر 100% zoom کی آخری بصری تصدیق تعیناتی کے بعد باقی ہے۔

## تدریسی نظرثانی — تازہ نسخہ

- 75 بنیادی سوالات ازسرنو مرتب؛ ہر سبق کی وجہ اور ضروری سابقہ مباحث واضح۔
- تمام 638 سوالات کے اختیارات کے ساتھ تشخیصی وضاحت؛ نحوی اور لفظی متبادل زیادہ متعلقہ بنائے گئے۔
- ایک عربی عبارت کی دوسری درست توجیہ کو مطلق غلط قرار دینے کے بجائے اصلاحی سوال میں مراد واضح؛ تجزیے کی غلطی اور لفظی عبارت کی غلطی کے الگ عنوان۔
- پہلی بار آنے والی اصطلاح کی قابلِ کلک وضاحت، 45 اصطلاحات اور چند مترادف aliases۔
- 75 مطالعے کے حصوں میں مکمل حرکات، آخری حرکات/تشدید کے اشارے اور بغیر حرکات؛ اصل متن تبدیل نہیں ہوتا۔
- 75 آزاد ترجمے کے خانے؛ اپنے جوابات پیش رفت کے ساتھ محفوظ، نمونہ جواب اور دلیل الگ۔ خودکار exact-match سے درست متبادل رد نہیں ہوتا۔
- مرحلہ وار مجموعی جانچ میں سابقہ مراحل؛ منتخب سوالات مراحل اور مہارتوں میں تقسیم، سابقہ progress IDs محفوظ۔

یہ خود انجام دی گئی علمی و تدریسی نظرثانی ہے؛ کسی بیرونی انسانی ماہرِ نحو کی توثیق ہونے کا دعویٰ نہیں۔ حقیقی browser visual QA کی مذکورہ حد بھی برقرار ہے۔
