# الحیات — آسان علم النحو

ڈاکٹر عمران حیات کی تدریسی پیشکش کے لیے مرتب ایک نیا، خود کفیل اردو تعلیمی ویب منصوبہ۔

## مواد اور استعمال

- 68 اسباق، 8 تدریجی مراحل؛ تعداد موضوعات کی ضرورت کے مطابق رکھی گئی ہے۔
- ہر سبق: نئی وضاحت، مکمل مثال و ترجمہ، 201 مجموعی لفظی اندراجات کے ساتھ اعراب، پورے جملے کی ترکیب، تقابلی مثال، اصلاح اور موضوعی سوال۔
- 606 سوالات: 68 مفہومی، 201 لفظی ترکیب، 68 اصلاحی، 201 سیاقی معنی اور 68 تطبیقی۔ اصلاحی سوال دو انتخاب رکھتا ہے؛ باقی چار۔
- ہر سبق کے الفاظ و معانی؛ مرکزی لغت میں 134 سیاقی اندراجات اور 28 نحوی اصطلاحات۔
- 68 اضافی مکمل تطبیقی مثالیں، اردو ترجمہ اور مفصل وجہ۔
- 340 سوال جواب کارڈ، 12 مختصر مرجعی جدول، ترکیب گاہ، تلاش، محفوظ اسباق، روشن/تاریک انداز اور پیش رفت کی منتقلی۔
- تکمیل کا نشان طالب علم خود اپنی مشق کے بعد لگاتا ہے؛ یہ خودکار سند نہیں۔ جانچ میں پہلی کوشش کا اسکور ہے۔ غلط سوال دوبارہ صحیح جواب دیکھنے کے باوجود دہرائی میں رہتا ہے؛ نئی جانچ میں پہلی کوشش درست ہو تو نکلتا ہے۔

`index.html` کھولیں۔ نصب کرنے، build، API، بیرونی font یا backend کی ضرورت نہیں۔ تمام fonts مقامی ہیں۔ پیش رفت browser localStorage میں محفوظ ہوتی ہے، کسی سرور پر نہیں جاتی۔

## Cloudflare Pages / GitHub Pages

ZIP نکال کر `nahw-learning` کے اندر موجود فائلیں repository کی root میں رکھیں۔ Cloudflare Pages میں framework: None، build command: خالی، output directory: `/`۔ GitHub Pages میں اسی directory کو source بنائیں۔ hash routes استعمال ہونے کی وجہ سے server fallback کی ضرورت نہیں۔ `upload` یا اصل PDFs شامل نہ کریں؛ یہ ZIP پہلے ہی ان کے بغیر ہے۔

## ترمیم

- `content.json`: مرتب درسی مواد اور سوالات۔ ترمیم کے بعد `node scripts/build-data.cjs` سے `data.js` تازہ کریں۔
- `vocabulary.js`: مرکزی درسی لغت؛ `terms.js`: نحوی اصطلاحات۔
- `reference.js`: مختصر قواعد کے جدول۔
- `app.js`: routes، مشق، ترکیب گاہ اور progress۔
- `styles.css`: رنگ، typography اور cards۔ `app-layout.css` آخر میں load ہونے والی viewport اور drawer ترتیب۔
- `editorial/`: ماخذ سے استفادہ، موضوعاتی نقشہ، جائزے کی حدود۔ یہ تدریسی تالیف ہے، اصل کتب کا لفظی نسخہ نہیں۔

Urdu: Jameel Noori Nastaleeq؛ Arabic: Amiri۔ الگ fonts اور نمایاں رنگ، متن پر blur/transform نہیں۔ پورے صفحے پر fixed minimum width یا zoom کم کرنے کی ترکیب استعمال نہیں ہوئی؛ طویل جدول کا scroll صرف اس کے اپنے خانے میں ہے۔

## جانچ

Node.js کے ساتھ: `node tests/smoke.cjs` اور `node --check app.js`۔ جانچ میں 204 درسی views، سوالات کی uniqueness، retry/scoring، محفوظ اسباق، progress، ترکیب گاہ اور static viewport contracts شامل ہیں۔ simulated DOM جانچ حقیقی browser rendering کا بدل نہیں؛ اس ماحول میں browser visual QA دستیاب نہیں تھی۔ تعیناتی پر desktop 1366×768، 1280×720، mobile 390×844 اور 320px width پر 100% zoom میں بصری جانچ باقی ہے۔

اپنی تدریسی ضرورت کے مطابق متن میں اضافہ کیا جا سکتا ہے۔ نحوی اختلاف کی صورتوں میں درج کردہ تحلیل ایک معروف منتخب توجیہ ہے؛ متبادل توجیہ کا امکان ختم کرنا مقصود نہیں۔
